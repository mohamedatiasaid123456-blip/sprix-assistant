- دعم قسم البرمجة للصف الأول الثانوي.
- دعم قسم البرمجة والثقافة المالية للصف الثاني الثانوي.

- فتح المنصات الرسمية مع دعم تسجيل الدخول بحساب الطالب.
- دراسة إمكانية تحسين تجربة متابعة الدروس والأسئلة داخل التطبيق.
