SPRIX Assistant 📚

تطبيق Android مساعد لمنصة SPRIX التعليمية، يهدف إلى مساعدة الطلاب على التدريب على البرمجة والثقافة المالية من خلال واجهة سهلة باللغة العربية.

🎯 أهداف المشروع

- دعم طلاب الصف الأول الثانوي.
- دعم طلاب الصف الثاني الثانوي.
- المساعدة في حل تدريبات البرمجة.
- المساعدة في حل تدريبات الثقافة المالية للصف الثاني الثانوي.
- قراءة الأسئلة وتحليلها واقتراح الإجابات المناسبة.
- توفير زر لتشغيل المساعدة التلقائية عند الحاجة.
- متابعة التقدم في التدريبات.

📚 الأقسام التعليمية

الصف الأول الثانوي

- البرمجة.
- الفصول والتدريبات البرمجية.

الصف الثاني الثانوي

- البرمجة.
- الثقافة المالية.
- الفصول والتدريبات الخاصة بكل قسم.

⚙️ المميزات المخطط تطويرها

- واجهة Android سهلة الاستخدام.
- اختيار الصف الدراسي والقسم التعليمي.
- عرض التدريبات ومساعدة الطالب على فهمها وحلها.
- المساعدة في كتابة الأكواد البرمجية ومراجعتها.
- المساعدة في الإجابة عن أسئلة الثقافة المالية.
- زر باسم «الحل التلقائي» لبدء المساعدة عند ضغط الطالب عليه.
- متابعة تقدم الطالب داخل التطبيق.

🛠️ التقنيات المخطط استخدامها

- Flutter لبناء تطبيق Android.
- Python عند الحاجة إلى خدمات خلفية.
- Playwright عند ملاءمته للتفاعل مع صفحات الويب المسموح بها.
- GitHub لإدارة ملفات المشروع.
- GitHub Actions للمساعدة في بناء ملف APK.
